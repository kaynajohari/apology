# Operation: Make My Boyfriend Stop Being Mad 💌

A fully client-side interactive apology game designed for GitHub Pages.

## Files

- `index.html`
- `style.css`
- `script.js`
- `assets/photo1.jpg` through `photo5.jpg`
- `assets/apology.mp4`

## Customize it

Open `script.js`.

At the very top, edit the `CUSTOM` object. This contains the boyfriend/girlfriend names, quiz questions, photo captions, apology text, and ending message.

## Add your photos/video

Put your five photos in `assets/` using these exact names:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`

Put the apology video here:

- `apology.mp4`

If a photo or video is missing, the website displays a cute placeholder instead of breaking.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Click **Save**.
8. Wait for GitHub Pages to publish the site.
9. Open the URL GitHub gives you.

No backend or build step is required.
